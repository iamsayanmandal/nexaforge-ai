# Images to PDF Conversion

## What is Images to PDF?
Combines multiple image files (JPG, PNG, WEBP) into a single PDF document.

## When to Use It
- Convert scanned images into a shareable PDF
- Combine multiple screenshots into one document
- Create a photo album PDF
- Submit scanned documents as PDF (required by many portals)

## How to Use in NexaForge
1. Upload multiple image files (JPG, PNG, WEBP)
2. Type: "convert these images to PDF" or "make a PDF from these images"
3. Or use the quick action button: **Images → PDF**

## Tips
- Upload images in the order you want them to appear in the PDF
- Each image becomes one page in the PDF
- All image formats are automatically converted to RGB (required for PDF)
- Transparent backgrounds (PNG with alpha) are replaced with white
- The PDF page size matches each image's dimensions
- There is no limit on number of images (within the 10MB total upload limit)

## Supported Input Formats
JPG, JPEG, PNG, WEBP, BMP

## Output
Single PDF where each page is one of your uploaded images.

## Common Use Cases
- Scanned documents: photograph each page, convert to PDF
- Identity documents: front + back photo → single PDF
- Portfolio: combine design screenshots into PDF presentation
- Reports: combine chart images + graphs into PDF document

## NexaForge vs Other Tools
NexaForge processes entirely in your browser session — no files stored on servers.
