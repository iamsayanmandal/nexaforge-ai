# Image Format Conversion

## What is Format Conversion?
Converting an image from one file format to another (e.g., JPG to PNG).

## When to Use It
- Need transparency support → convert to PNG
- Need smallest file size for web → convert to WEBP
- Website requires specific format
- Converting PNG screenshots to JPEG for sharing

## How to Use in NexaForge
Type instructions like:
- "convert to PNG"
- "change format to WebP"
- "make it a JPEG"
- "convert to jpg"

Or use the quick action button: **Convert Format**

## Supported Formats
| Format | Best For | Transparency | File Size |
|--------|----------|--------------|-----------|
| JPEG/JPG | Photos, complex images | No | Small |
| PNG | Graphics, logos, screenshots | Yes | Medium |
| WEBP | Web images (modern browsers) | Yes | Smallest |

## Tips
- WEBP is ~25-35% smaller than JPEG at similar quality
- PNG preserves transparency — use for logos, icons
- Converting PNG→JPEG loses transparency (replaced with white background)
- WEBP is supported by all modern browsers (Chrome, Firefox, Safari, Edge)

## Common Use Cases
- Logo file: PNG (for transparency)
- Website photo: WEBP (fastest loading)
- Email attachment: JPEG (most compatible)
- Social media: JPEG or PNG
