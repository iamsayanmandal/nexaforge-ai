# PDF Merge

## What is PDF Merging?
Combining multiple PDF files into a single PDF document.

## When to Use It
- Combining multiple chapters or sections into one document
- Merging scanned pages into one file
- Combining a cover letter + resume + certificate into one PDF
- Creating a report from multiple PDF exports

## How to Use in NexaForge
1. Upload multiple PDF files (click the upload zone and select 2+ files)
2. Type: "merge these PDFs" or "combine into one PDF"
3. Or use the quick action button: **Merge PDFs**

## Tips
- Pages appear in the order you upload the files
- To control page order, name files: 01_intro.pdf, 02_body.pdf, 03_conclusion.pdf
- There is no limit on number of PDFs to merge (within the 10MB total upload limit)
- The merged PDF preserves all original formatting, fonts, and images

## Common Use Cases
- Job applications: merge resume + cover letter + certificates
- Reports: merge executive summary + data + appendix
- Legal documents: combine all related pages into one filing
- Books: combine chapters

## Output
Single PDF with all pages from all input PDFs, in upload order.
