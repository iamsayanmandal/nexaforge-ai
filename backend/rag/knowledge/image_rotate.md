# Image Rotation

## What is Image Rotation?
Rotating an image by a specified angle (90°, 180°, or 270° clockwise).

## When to Use It
- Photo taken in wrong orientation (phone camera)
- Scanned document is sideways
- Need to flip image orientation for a presentation

## How to Use in NexaForge
Type instructions like:
- "rotate 90 degrees"
- "rotate clockwise 90"
- "flip upside down" (= rotate 180)
- "rotate 270 degrees"

Or use the quick action button: **Rotate Image**

## Rotation Options
| Degrees | Effect |
|---------|--------|
| 90 | Rotates clockwise (landscape → portrait) |
| 180 | Flips upside down |
| 270 | Rotates counter-clockwise (portrait → landscape) |

## Tips
- The canvas expands to fit the rotated image — no cropping
- For a photo that appears sideways on your phone, try 90° rotation
- Multiple rotations: process twice (e.g., two 90° = one 180°)

## Common Use Cases
- Correcting sideways photos from phones
- Rotating scanned documents
- Adjusting orientation for slide presentations
